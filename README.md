# water Paotability 
Water Quality Analysis is a Python-based data analysis project that evaluates water quality using the Water Potability dataset. It performs data cleaning, statistical analysis, visualization, correlation analysis, outlier detection, and linear regression to study the relationship between pH and water potability. The project also categorizes water as Acidic, Normal, or Alkaline based on its pH level.

Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
